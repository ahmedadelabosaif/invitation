# Invitation

- Public invitation: https://ahmedadelabosaif.github.io/invitation/
- Visual editor: https://ahmedadelabosaif.github.io/invitation/admin.html

The visual editor opens directly at `/admin.html`. To publish without copying
data, create a GitHub fine-grained personal access token limited to this
repository with **Contents: read and write** permission. Enter the token in the
editor, then use **Preview** and **Publish**. The token is used for the GitHub
API request and saved in this browser's local storage so later visits can
publish without re-entering it. Use **Change token** to replace it or **Forget
token on this device** to remove it. Only save it on a trusted device; browser
storage is accessible to scripts running on this site. GitHub commits the
invitation update; GitHub Pages deploys it automatically.

Use **Add event** to create another invitation, **Set as main invitation** to
choose what appears at the main link, and **View guest link** to open one
event. Add an optional map URL to make a **Get directions** link appear on the
public invitation. Choose **Islamic wedding** for an emerald-and-gold palette
with subtle crescent-and-star animation. Separately, select any optional guest
etiquette notes (for example no photos or video, modest dress, separate
seating, prayer space, halal food, or no music) to show them on the invitation.
Upload a JPG, PNG, or WebP to add an optional card image or full-page background;
the editor optimizes it and stores it with the published site. You can also add
a direct HTTPS MP3/OGG URL. Guests control playback with play/pause and mute
buttons; music never starts automatically. Changes are drafts until published.
Uploaded images and event data are public, so only use content you want to
share with guests.
